# ⚡ GridPulse — Smart Microgrid Supervisory Control Dashboard

**GridPulse** is an Industrial Internet of Things (IIoT) supervisory control and data acquisition (SCADA) web dashboard model built for modern microgrids and smart power systems. Developed for **Government Engineering College, Madhubani** (Department of Electrical Engineering).

---

## main Features

* **Real-Time Telemetry (1 Hz Sampling):** Dynamic line curve tracking for 415V/11kV bus voltage and feeder load current.
* **Power Quality & Reactive Power Support:** Real-time power factor ($\cos\phi$) monitoring with on-demand Shunt Capacitor Bank compensation.
* **Automated Tiered Load Shedding:** Emergency load management prioritizing critical infrastructure (**Tier 1: Emergency Load Hospital/ICU**) while shedding non-critical feeders during grid trips.
* **Asset Health Monitoring:** Condition-based health index factoring thermal rise and load stress to track equipment status.
* **Environmental Offset Tracker:** Live calculations of $\text{CO}_2$ emissions saved based on solar displacement ($0.82 \text{ kg CO}_2/\text{kWh}$).
* **Telemetry Data Export:** One-click timestamped CSV export for relay logs and sensor data analysis in Microsoft Excel.
